Reusable AndHub brand skill.

The andhub-brand skill contains scoped instructions and links to current sources. It helps with AndHub copy, interfaces, templates and resource selection.

  1. Download the skill’s SKILL.md or take the assets/ai/andhub-brand/ directory from the repository or AI bundle.
  2. Keep the folder with the project, or import it using the skill workflow supported by your assistant. No global configuration is changed by this website.
  3. Ask your tool to use that skill for the AndHub task. In a local checkout, current facts are available in assets/brand.json and assets/ai/brand-context.json.

The root AGENTS.md supplies repository guidance for coding assistants that recognize it. The skill and repository instructions preserve the user’s current scope and permissions.

A real read-only local MCP adapter.

The adapter implements newline-delimited JSON-RPC over stdio for MCP 2025-11-25. It reads fixed local brand sources and the catalog, returns published download URLs, and offers no write tools or arbitrary file access.

  1. Download a complete repository checkout or the portable AI bundle. Keep its folder structure so assets/ai/mcp-server.mjs can find the brand context and resource index.
  2. Have Node.js 22 or newer available. The adapter uses the Node standard library and needs no package installation.
  3. Add the following entry through your MCP client’s supported local-server settings. Replace the placeholder with the actual absolute file path.
{
  "mcpServers": {
    "andhub-brand": {
      "command": "node",
      "args": ["/PATH/TO/branding-guideline/assets/ai/mcp-server.mjs"]
    }
  }
}

On Windows, use forward slashes or escaped backslashes in the JSON path. If your client cannot find node, use the full path to its Node executable as the command. Configuration shapes differ between clients; the example shows a common local stdio layout.

From a checkout, run the protocol smoke test with node scripts/check-mcp.mjs. Launching the adapter directly with node assets/ai/mcp-server.mjs waits for an MCP client on stdin; silence is expected. Only protocol messages are written to stdout.

Fixed readable resources are andhub://brand-context, andhub://brand-data, andhub://brand-spec, andhub://guidelines and andhub://catalog. The optional andhub_brand_brief prompt combines a caller-supplied task with current context.

Local adapter, static hosting. GitHub Pages serves the source and context files. It does not run this adapter or provide an HTTP MCP endpoint. Your client must support launching a local stdio server; cloud-only clients may need the URL or attachment approach instead.
