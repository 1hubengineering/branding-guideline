# Legacy AndHub logos and design mockups

These 13 original raster files were supplied in `assets/images/reference/temp` and are retained unchanged here with descriptive filenames. The [inventory](legacy-assets.json) records original filenames, SHA-256 hashes and front/back pairings.

The collection contains an old metallic logo, four business-card concepts, a two-sided brochure and two identity/concept boards. These are historical references, not current logo masters or editable/print-ready templates. Printed names, contact details, old taglines and placeholder graphics may be outdated. Use [current company data](../brand.json) for new work and the current vector masters for the logo.
