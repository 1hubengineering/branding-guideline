# AndHub supporting typography

Unmodified Inter variable font files from the [official Inter project](https://github.com/rsms/inter), downloaded 2 November 2026.

- [InterVariable.ttf](InterVariable.ttf): desktop installation and editable design templates.
- [InterVariable.woff2](InterVariable.woff2): self-hosted web font, upright styles, weights 100–900.
- [InterVariable-Italic.woff2](InterVariable-Italic.woff2): self-hosted web font, italic styles, weights 100–900.
- [SIL Open Font License](LICENSE.txt): keep this license with font redistributions.

Source files: `docs/font-files/` on the official project's `master` branch. The variable font's optical size axis supports text and display use. The AndHub logo lettering remains outlined vector artwork and does not depend on these fonts. The original guideline documents predate this font distribution; fonts are now included in this library.

Use the **Fonts** category in the [asset library](../../assets.html?category=fonts) for individual files or the licensed ZIP bundle. [Back to home](../../index.html).
